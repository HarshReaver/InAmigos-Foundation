## Task 1 — NGO Awareness Webpage

A single-page awareness website for InAmigos Foundation covering all 6 projects, events, gallery, and call-to-action sections.

- **Tech:** HTML, CSS, Font Awesome, Google Fonts
- **Live Demo:** [harshreaver.github.io/InAmigos-Foundation](https://harshreaver.github.io/InAmigos-Foundation/)
- **Details:** [Task 1/README.md](Task%201/README.md)

## Task 2 — Website Improvement Analysis

Analyzed the official InAmigos Foundation website and identified 6 key issues — spam link injection, disabled donate button, empty causes page, spelling errors, broken gallery, and SEO gaps.

- **Output:** Markdown document with screenshot placeholders
- **Details:** [Task 2/Website_Improvement_Analysis.md](Task%202/Website_Improvement_Analysis.md)

## Task 3 — AI Website Generation

Built a complete SaaS landing page (NexusAI) using AI tools. Includes hero, features, pricing, testimonials, FAQ, and footer sections.

- **Tech:** HTML, CSS, JavaScript
- **AI Tool Used:** Google Gemini
- **Details:** [Task 3 - AI Website/README.md](Task%203%20-%20AI%20Website/README.md)

## Task 4 — NGO Feature Highlights

Design presentation highlighting 5 essential features for an NGO website — donation section, volunteer form, impact dashboard, testimonials, and campaign highlights. Each feature includes a browser-frame mockup and annotated explanations.

- **Tech:** HTML, CSS
- **Details:** [Task 4 - NGO Features/](Task%204%20-%20NGO%20Features/)
