## About

**NexusAI** is a fictional AI-powered data analytics SaaS platform. This website was generated entirely using AI to demonstrate how AI tools can build professional, production-ready websites from scratch.

## Tech Stack

- **HTML5** + **CSS3** (no frameworks)
- **Font Awesome 6** — icons
- **Google Fonts** — Inter (body) + JetBrains Mono (code)
- **Vanilla JavaScript** — scroll animations, FAQ accordion, mobile menu

---

## AI Tool Details

This website was built using **Google Gemini (Antigravity)**, an AI coding assistant. The entire process — from design decisions, colour palette, layout structure, CSS animations, to responsive breakpoints — was handled by the AI based on a single prompt.

**What the AI did:**
- Chose the domain (SaaS/tech startup)
- Designed the dark-mode colour palette with gradient accents
- Wrote all HTML structure with semantic elements
- Created the complete CSS with responsive design
- Added JavaScript for interactivity (FAQ, navbar, animations)
- Generated realistic placeholder content (pricing, testimonials, features)

**Time taken:** Under 5 minutes
